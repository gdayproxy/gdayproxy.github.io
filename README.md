# G'DAY PROXIAN

Это проект с открытым исходным кодом, где автор публикует откопанные им же MTProto и даже Web прокси

Кстати недавно появилось зеркало на [Surge.sh](https://gdayproxy.surge.sh)

Используйте, если у вас не работает версия на [Github Pages](https://gdayproxy.github.io)

\* Переключаться между ними легко оба начинаются на `gdayproxy.`, а дальше либо `github.io` либо `surge.sh`
